# CITY DRIVE 20 — Offline Android driving simulator

Native Android Java road-driving arcade prototype. 24 selectable named real-world vehicle models (illustrated, not licensed 3D assets), racing, taxi, driving school, free drive and off-road. Works offline after installation. Android 13 target. Build APK in GitHub Actions.

**Limitations:** stylized 2D perspective graphics, not realistic 3D models or a photo-real city. Vehicle names are references to real-world makes/models, not licensed representations.

APK: Actions → Build APK → successful run → Artifacts → CityDrive20-Android13.
